## Открытые

### P-45 🟢 Шаг 0 пилота: отступления от плана (2026-11-05)
- **[Факт] Dev-служебный бот и группа DEV отложены до шага 2** (решение владельца). Шаг 0 проверен только на dev-клиентском боте: проверки «`/start` служебного» и «заявка в группу DEV» не выполнялись. `TELEGRAM_BOT_TOKEN` в Vercel — одна запись на Production и Preview. Для ветки `feature/bot-clients` поверх неё заводятся свои значения, остальные ветки Preview работают с боевым токеном, а ADR-0006 §8 предполагает dev-ботов на всём Preview.
- **[Факт] `APP_URL` в Production отложен до шага 6** (решение владельца): сайт его пока не читает, только локальный скрипт. В плане он стоит на шаге 0, а в списке Production шага 6 его нет.
- **[Факт] В `bot:webhook` добавлено сверх плана:** режим `--info`, отказ уводить вебхук с `skorouvas.cz` без `--force`, ошибка без `APP_URL` вместо прод-адреса по умолчанию, маскировка секретов в выводе. Из `APP_URL` в адрес вебхука идёт только `x-vercel-protection-bypass`: `x-vercel-set-bypass-cookie` отвечает редиректом.
- **[Факт] Боевой вебхук.** Владелец поправил токен в Vercel и сообщил, что `--info` боевого бота в порядке (2026-11-05). Вывод агент не видел.
- **Нужно от архитектора:** добавить `APP_URL` в список Production шага 6 плана; закрыть строку про 500 в CURRENT §9.
