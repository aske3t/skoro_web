## Кратко

Сайт курьерской службы Skoro (Брно, CZ): лендинг с калькулятором, контактная форма (лиды), личный кабинет B2B-клиента и два Telegram-бота — служебный (заявки, заказы) и клиентский (пилот).
Стек: Next.js 15.5.27, React 19, TypeScript, Tailwind 3, Supabase (`@supabase/ssr` 0.12.7, `supabase-js` 2.117.2), zod, vitest 5, ESLint 9. Node 22 LTS.
Дорожная карта — [CURRENT.md §10](architecture/CURRENT.md). TASK-001 и TASK-002 влиты в `dev`. TASK-003 влит в `dev` (PR #3, 2026-10-13) и перенесён в [tasks/003-static-landing.md](tasks/003-static-landing.md). Прод переключён на `main`.

## Отклонения и вопросы

**2026-11-05…12, пилот клиентского бота:**
- **Два бота вместо одного** — решение владельца; ADR-0006 изменён архитектором (P-43, пак 2026-11-05).
- **Dev-служебный бот** заведён не на шаге 0, а перед шагом 2; `APP_URL` в Production — на шаге 6 (P-45).
- **`session()` grammY не подключён:** шагам 3–4 состояние диалога не нужно (P-46).
- **Страницы сайта перенесены в `(site)`**, у Mini App свой корневой layout; 404 на неизвестных адресах теперь стандартная, без шапки и футера (P-47).
- **Решения владельца на шагах 2–4:** ночная заявка «как можно скорее» принимается; одна опция тоже открывается кнопкой; `form_defaults` только предзаполняет; код `invalid_time` — только у превью цены (P-48).

- **Импорты в `lib/leads`** (`schema`, `ico`, `phone-format`) переведены на `.ts`-расширения: эти модули теперь загружают скрипты ботов без бандлера.

## Как запустить и проверить

```bash
npm install
cp .env.example .env.local   # заполнить, см. README → Environment variables
npm run dev                  # http://localhost:3000
npx tsc --noEmit && npm run lint && npm test && npm run build   # то же, что CI
```

- Supabase CLI (из сети владельца):
  ```bash
  read -s SUPABASE_ACCESS_TOKEN && export SUPABASE_ACCESS_TOKEN
  read -s DB_URL && export DB_URL   # строка Session pooler с паролем БД
  npx supabase migration list --db-url "$DB_URL"
  ```
- Генерация типов — через временный файл (см. `CLAUDE.md`).
- Вебхук бота: `npm run bot:webhook` (нужны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET` в `.env.local`, совпадающие с Vercel); снять — `npm run bot:webhook -- --delete`.
- Разбор UI: `/impeccable critique <файл>`; снимки — `.impeccable/critique/`.
- Для ЛК нужен пользователь в Supabase Auth: аккаунты создаёт владелец.
- Плейсхолдеры владельца: `grep -rn "TODO(владелец)" src`.
- Боты (значения dev-ботов — в `.env.local`): `npm run bot:webhook -- --bot service|client [--info|--delete]`, `npm run bot:commands -- --bot service|client`, `npm run bot:dev -- --bot …` (только при снятом вебхуке этого бота). Подробно — [telegram-bot.md](telegram-bot.md), настройка Preview — [ops/telegram-dev.md](ops/telegram-dev.md).
- Клиенты пилота, проверки и уборка тестовых данных — [ops/clients.md](ops/clients.md).
- Mini App открывается только из клиентского бота («🆕 Новый заказ»); вне Telegram страница пишет «Откройте форму через бота».
- `npx tsc --noEmit` не проверяет скрипты `scripts/*.mts`: их нет в `include` tsconfig.
- **Не проверено:**
  - анимация футера и hover сот «О работе с нами» в настоящем браузере;
  - отправка подписки (нужна применённая миграция `20261030120000`);
  - CI на GitHub;
  - Autocomplete и time-trap в браузере;
  - форма нового заказа (P-14).
